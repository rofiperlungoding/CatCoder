6. Authentication & Security

6.1 Authentication Flow

User enters email → Supabase sends Magic Link → User clicks link → Callback handler → Session created → Profile loaded → Dashboard redirect

6.2 Row Level Security (RLS)

Table Policy Description
profiles SELECT Public (for leaderboards)
profiles UPDATE Own profile only
user_progress SELECT Own progress + public for leaderboard
user_progress INSERT/UPDATE Own progress only
problem_answers SELECT Public (read answers for validation)

6.3 XP Security

XP cannot be arbitrarily updated by clients. The validate_and_complete() function uses SECURITY DEFINER to:

  • Validate user output against stored expected output
  • Award XP only if correct
  • Prevent duplicate XP awards

6.4 Content Security Policy

The application implements a strict CSP header to prevent XSS attacks:

  • Scripts limited to self and CDN sources
  • Connections restricted to Supabase endpoints
  • Worker sources for Pyodide WebAssembly
